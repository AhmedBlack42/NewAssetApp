# Phase 5 Location Taxonomy

Canonical locations: `bathroom,bar,beach,cafeteria,class,clinic,coffee_shop,home,locker_room,mall,office,park,pier,shower,lounge`. Existing YOLO mappings remain only where explicitly documented (`home,class,office,bathroom,bar`); `location_outdoor` and `location_bed` are unmapped. The original YOLO class IDs/names are preserved.
